Рабочий сценарий
Рекрутер нанимает middle python-разработчика. 

Рекрутер загружает вакансию и ссылку на прохождение интервью.
Кандидат загружает резюме и кликает на ссылку. 
Кандидата читает гайд по прохождению интервью и приступает к прохождению.  

Проверка
Happy path
Кандидат указал в резюме бэкграунд и опыт. LLM сформировала оценку и короткий комментарий.

Fallback Path
Кандидат указал в резюме мало информации. LLM оставит комментарий: мало данных для выставления оценки.


Метрики
Релевантность профиля кандидата относительно профиля вакансии. 
Оценки:
1 - если нет стоп-факторов
0 - если есть стоп-факторы
-1 - мало данных для выставления оценки

Риски
Почти всех одобрит
