# Краткая аннотация проекта

Команда разрабатывает систему проведения интервью, в которой оценка кандидата выполняется с помощью ИИ-помощника. Цель — автоматизировать первичный отбор разработчиков и повысить эффективность работы рекрутеров.

---

## Проблематика

Рекрутеры сталкиваются с высоким потоком откликов на IT-вакансии. Это приводит к нехватке времени на качественную проверку каждого кандидата, что снижает точность отбора наиболее релевантных специалистов для дальнейшего общения с нанимающим менеджером.

---

## Актуальная постановка задачи

Создать систему, способную автоматически оценивать соответствие кандидата требованиям вакансии на основе данных из резюме и результатов технического интервью.

---

## Выбранное техническое решение

Система состоит из следующих модулей:

- **Платформа проведения интервью** — с функциями записи, сохранения данных и синтеза речи (TTS).
- **Лидерборд кандидатов** — для ранжирования и сравнения соискателей.
- **Личные кабинеты** для трёх типов пользователей:
  - Нанимающий менеджер
  - Рекрутер
  - Кандидат

## План работ до финальной версии

1. Разработать интерфейсы для нанимающего менеджера, рекрутера и кандидата.
2. Детально описать логику оценки кандидатов.
3. Разделить функционал на базовый (для PoC) и целевой (для продакшена).
4. Реализовать базовый функционал для PoC.
